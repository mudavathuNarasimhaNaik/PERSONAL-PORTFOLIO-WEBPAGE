💻 Frontend Portfolio Website – Project Description.
This portfolio website is a self-designed and fully responsive project built exclusively using HTML5 and CSS3. It serves as a personal showcase for my web development skills and includes various sections like Home, About Me, My Projects, Certificates, and Contact. The main goal of this project is to demonstrate how powerful and visually engaging a website can be—using just core web technologies without JavaScript or frameworks.

The Home section offers a clean and modern welcome with my name, title (“Frontend Developer”), and a professional image. This section uses centered content and a vibrant background that highlights my identity and role. Flexbox ensures that the content remains vertically and horizontally aligned across all screen sizes.

The About Me section provides a brief overview of my background, passion for design, and web development journey. This part of the website features a two-column layout with text and an image, styled using Flexbox. Padding, margins, and custom fonts are used for a clean and readable design.

In the My Projects section, I showcase three frontend-based static projects that are completely developed using HTML and CSS:

Agri IoT UI – A farming dashboard-style layout designed for crop monitoring using placeholder content and info cards.

E-Learning Platform Layout – A structured educational website mockup with sections for courses, instructors, and media.

Quiz App UI – A quiz interface with radio button-styled options, result placeholders, and form elements, built as a frontend template.

Each project is styled using Flexbox and Grid for layout organization. Hover effects and transitions are used to enhance interactivity without JavaScript.

The My Certificates section displays real certificates in a grid layout. Each certificate image is responsive and includes subtle hover animations using CSS transitions. This section validates my technical learning journey in areas like DBMS and Deep Learning.

The Contact Me section contains a styled HTML form with inputs for name, email, and message. Though not connected to a backend, the form design is fully responsive and uses consistent input styling with focus states, making it look professional and ready for integration.

Across the entire website, consistent color schemes, Google Fonts, and CSS variables are used to maintain a cohesive and appealing design. All elements are optimized for responsiveness using media queries.

This project highlights my ability to plan, structure, and execute a fully functional static website using only fundamental frontend tools. It reflects my creativity, discipline in layout design, and commitment to clean, maintainable code.
